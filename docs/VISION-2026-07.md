# Hearthmind — Long-Term Design Vision Roadmap (July 2026)

**Status: fully shipped.** This was originally the audit + sequencing
document for the user's 2026-07-16 long-term design vision ("living
civilization simulator", "maximize emergence per LLM call", two-layer
engine, hierarchical intelligence, Town Consciousness, Narrative
Direction). All six phases it sequenced (I–N) have since shipped —
see CLAUDE.md's "Long-term design vision" section for the compact
standing summary, and CHANGELOG.md for the version-by-version detail
of each phase landing. Trimmed to a status pointer 2026-07 (the
now-fully-shipped-checklist doc gets the same treatment
`docs/ROADMAP.md` got for the original Phase A-H backlog) — nothing
lost, full original audit/rationale text lives in git history and is
otherwise superseded by what actually shipped.

## The two flagged conflicts — both resolved as proposed, no override given

1. **Core cast size**: vision text said "~11"; the tuned default (14,
   v0.72.4, live-hardware-derived) was kept as the governing number —
   "~11" read as an order-of-magnitude intent, not a hard requirement,
   and the CLI lever to set it literally already existed. No user
   override was ever given, so this stands.
2. **"Town Consciousness may directly cause events"** vs. Phase G's
   permanent "never escalate toward anything explicit": resolved as
   deniable-channels-only — Phase N's `ALLOWED_INTERVENTIONS`
   (weather/temperament nudges, false memories, misplaced objects,
   omen/dream seeds) never includes anything a player could only read
   as supernatural. This is the shipped, governing interpretation.

## Standing principles (still governing, unchanged)

"Maximize emergence per LLM call" remains the concrete test for any
new LLM-touching feature — see CLAUDE.md's "Long-term design vision"
section. Mandatory audit-before-feature; extend existing systems
before adding parallel ones; every mechanic should interact with
multiple others; the design test is "will this make the world feel
more alive even if the player never interacts with it?" No further
phase beyond N is pre-defined — `docs/IDEAS-2026-07-EMERGENCE.md`
picked up where this document left off (2026-07-19) and is itself now
fully resolved too (see its own status note).
